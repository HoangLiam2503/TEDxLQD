# Git Workflow

- New branch per task: `feat/` `fix/` `chore/` prefixes.
- Commit only when explicitly asked or a logical unit is complete.
- Never force-push to main.
- Conventional commits: `feat:` `fix:` `docs:` `style:` `refactor:`
- Add `./screenshots/` to `.gitignore` (generated files, not source).
- Commit `./refs/` to git (reference images are source truth).
