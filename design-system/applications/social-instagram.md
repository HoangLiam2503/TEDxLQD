# Instagram — Application Guidelines

## Canvas
- **Feed post:** 1080×1080px (square) or 1080×1350px (portrait)
- **Story / Reel cover:** 1080×1920px
- **Background:** `#141414` (brand canvas — never white)

## Typography on Instagram
- Headline: Fraunces 700–900, white `#f0ede8`
- Body: Be Vietnam Pro 400–500
- Minimum readable size: 32px at export resolution

## Color usage
- Primary accent: `#eb0028` for borders, underlines, badges
- Never red backgrounds on large areas
- Grain overlay: add subtle noise for texture (matches web)

## Content types

### Speaker announcement
- Speaker portrait (full-bleed or 60% of frame)
- Overlay: dark gradient bottom-to-top
- Text: Number + Topic + Name + Role
- Red thin line or dot as accent

### Event countdown
- Dark canvas
- Large Fraunces number (days remaining)
- "TEDxLe Quy Don HS Binh Dinh · 28.06.2026" small label

### Quote card
- Playfair Display italic for the quote
- Attribution in Be Vietnam Pro
- Thin red left border or underline
