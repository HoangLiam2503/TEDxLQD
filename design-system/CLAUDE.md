# CLAUDE.md — TEDxLe Quy Don HS Binh Dinh Design System

Load this file first whenever producing any asset for this brand.

## Non-negotiables

1. **Canvas is always `#141414`** — not white, not black. Warm near-black.
2. **One primary color: `#eb0028`** — TED red. Used only on CTAs, accents, and the "TED" wordmark. Never as a large background fill.
3. **Display font: Fraunces** — all headings. Never Inter, Roboto, or system-ui for headlines.
4. **Body font: Be Vietnam Pro** — Vietnamese-optimized. Always available via Google Fonts.
5. **Sentence case** — all headlines. No Title Case. No ALL CAPS except ≤3-word labels.
6. **Vietnamese copy** — all public surfaces. Second person ("bạn"). Short sentences. No hype words.
7. **No gradients on large areas** — use solid `#141414` or `#1c1d1d`. Gradients only as subtle overlays on images.
8. **No stock photos** — real people, real event photography only.
9. **Motion: fade + small translate only** — 160–900ms. No parallax, no scroll-jacking.
10. **Every claim needs a number** — "150+ khán giả," "8 diễn giả," "139.000 ₫." Never vague.
