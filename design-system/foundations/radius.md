# Border Radius

| Context | Value | Usage |
|---------|-------|-------|
| Pills (buttons, badges) | `999px` | CTAs, nav button, tags |
| Cards (modal, panels) | `20px` | Checkout modal, FAQ contact box |
| Inputs | `10px` | Form fields |
| Small elements | `8px` | Disclaimer box, small cards |
| Speaker cards | `0` | Sharp edges — editorial feel |
| Image portrait | `0` | No radius on speaker photos |
